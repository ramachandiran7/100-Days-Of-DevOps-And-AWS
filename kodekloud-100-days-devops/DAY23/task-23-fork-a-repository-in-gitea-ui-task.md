# Day 23: Fork a Repository in Gitea (UI task)

| | |
|---|---|
| **Day** | 23 of 100 |
| **Phase** | 2 · Git |

## 📌 Task

Log in to Gitea as `<USER>` and fork `<OWNER>/<REPO>`.

## 🔁 Values to change before you run

Replace each of these with the value from **your** task: `<OWNER>` `<REPO>` `<USER>`

## ✅ Solution (copy and paste)

1. Click the **Gitea UI** button in the lab's top bar.
2. Sign in with the username and password from the task.
3. Search or open `<OWNER>/<REPO>` (e.g. `sarah/story-blog`).
4. Click **Fork** (top right).
5. Owner = your user (e.g. `jon`), keep the repo name, click **Fork Repository**.
6. Confirm the URL is now `<USER>/<REPO>` and it shows "forked from <OWNER>/<REPO>".

## 🧪 Verification

📸 Screenshot: the forked repo page.

## 🛠️ Common Issues & Fixes

| Issue you may see | Fix |
|---|---|
| No Fork button | You are logged in as the wrong user or on the wrong repo. |
| The fork has the wrong owner | Choose the correct owner in the fork dialog. |
| Cannot find the repo | Search `<OWNER>/<REPO>` under Explore, then Repositories. |
